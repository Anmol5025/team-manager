# Ethara Assignment - Full Stack Application

This is a full-stack application consisting of a React + Vite frontend and a Node.js backend.

## Project Structure

- `/frontend`: React application built with Vite.
- `/backend`: Node.js server.

## Getting Started

### Prerequisites
- Node.js
- npm or yarn

### Frontend Setup
1. Navigate to the frontend directory: 
   ```bash
   cd frontend
   ```
2. Install dependencies: 
   ```bash
   npm install
   ```
3. Start the development server: 
   ```bash
   npm run dev
   ```

### Backend Setup
1. Navigate to the backend directory: 
   ```bash
   cd backend
   ```
2. Install dependencies: 
   ```bash
   npm install
   ```
3. Start the server (setup your `.env` first based on the `.env.example` if it exists): 
   ```bash
   npm run dev
   ```
   *(Or standard start command like `npm start` or `node server.js`)*

## Features & Functions

### Authentication & Authorization
- Secure User Authentication (Signup & Login)
- JWT (JSON Web Tokens) based session management
- Role-Based Access Control (RBAC)

### Dashboard
- Comprehensive overview of activities and statistics
- Responsive, premium UI design

### Project Management
- Create, view, update, and delete projects
- Role-specific visibility and control over project details

### Task Management
- Assign tasks to team members
- Track task status and progress
- Organize and categorize tasks effectively

## Technologies
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB (Mongoose)
