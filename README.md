# Ethara Assignment - Full Stack Application

This is a full-stack application consisting of a React + Vite frontend and a Node.js backend.

## Project Structure

- `/frontend`: React application built with Vite.
- `/backend`: Node.js server.

## Getting Started

### Prerequisites
- Node.js
- npm or yarn

### Frontend Setup
1. Navigate to the frontend directory: 
   ```bash
   cd frontend
   ```
2. Install dependencies: 
   ```bash
   npm install
   ```
3. Start the development server: 
   ```bash
   npm run dev
   ```

### Backend Setup
1. Navigate to the backend directory: 
   ```bash
   cd backend
   ```
2. Install dependencies: 
   ```bash
   npm install
   ```
3. Start the server (setup your `.env` first based on the `.env.example` if it exists): 
   ```bash
   npm run dev
   ```
   *(Or standard start command like `npm start` or `node server.js`)*

## Technologies
- **Frontend:** React, Vite
- **Backend:** Node.js, Express (and MongoDB based on the models)
